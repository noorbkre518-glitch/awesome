# Country Launch Checklist — قائمة فتح دولة

لا تُفتح أي دولة قبل اكتمال جميع البنود بأدلة موثقة:

- [ ] صف/صفوف الدولة مكتملة ومعتمدة في Payment Compliance Matrix.
- [ ] صف/صفوف الدولة مكتملة ومعتمدة في Data Residency and Transfer Matrix.
- [ ] مراجعة قانونية محلية نهائية (عمر، محتوى، خصوصية، دفع، أرباح، ضرائب).
- [ ] موافقات المزودين تغطي الدولة (vendor_approvals).
- [ ] وسائل الدفع المحلية مفعلة ومختبرة عبر feature_flags.
- [ ] العملة والتوقيت واللغة والدعم المحلي مهيأة (قسم 19).
- [ ] متطلبات سحب الأرباح للمنشئين في الدولة متحقق منها.
- [ ] تهيئة المتجرين للدولة مختبرة + store_submission_records محدث.
- [ ] معايير القبول المعمارية مجتازة على تهيئة الدولة.
- [ ] موافقة صاحب المشروع النهائية على فتح الدولة.
