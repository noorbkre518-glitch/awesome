# CONTRIBUTING — قواعد المساهمة

المرجع: القسمان 34 و41 من [`PROJECT_MASTER_PLAN.md`](PROJECT_MASTER_PLAN.md).

1. هذا هو المستودع الدائم للمشروع — لا مستودعات جديدة.
2. فرع مستقل لكل تغيير (planning/…, design/…, feature/…).
3. كل تعديل عبر Pull Request مع مراجعة قبل الدمج؛ لا كتابة مباشرة إلى main.
4. الخطة الأم لا تُعدَّل بصمت: Issue (قالب Plan Change Request) → موافقة صاحب المشروع → تعديل + CHANGELOG + docs/DECISION_LOG.md.
5. ممنوع رفع: كلمات مرور، مفاتيح، رموز دخول، بيانات بنكية، وثائق هوية، ملفات أسرار، بيانات مستخدمين حقيقية.
6. لا كود تطبيق قبل إنهاء المراجعات الثلاث وموافقة صاحب المشروع.
7. لا توصف خطوة بأنها مكتملة دون دليل (اختبار أو تحقق موثق).
