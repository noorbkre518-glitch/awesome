# تشغيل Aurora على هاتف Android

1. ثبّت Docker Desktop وNode.js على Windows.
2. اجعل الهاتف والكمبيوتر على شبكة Wi-Fi نفسها.
3. انقر مرتين على `START_AURORA_WINDOWS.bat`.
4. انتظر حتى يظهر عنوان مثل `http://192.168.1.20:3000/api`.
5. ثبّت ملف Debug APK على الهاتف.
6. أدخل العنوان الظاهر في شاشة Aurora واضغط **اختبار الاتصال**.
7. بعد نجاح الاتصال، أنشئ حسابًا أو سجّل الدخول.

إذا فشل الاتصال، اسمح للمنفذ 3000 في Windows Firewall وتأكد أن الهاتف والكمبيوتر على الشبكة نفسها. نسخة Release تتطلب HTTPS؛ للاختبار المحلي استخدم Debug APK.
